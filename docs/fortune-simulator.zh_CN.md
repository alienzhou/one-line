# 在 Mac 上运行一签

在 Finder 中双击 `tools/Launch-Fortune-Simulator.command`，或执行：

```bash
python3 tools/fortune_simulator/server.py
```

启动器编译桌面适配程序，并打开 `http://127.0.0.1:8786/`。
保持终端运行；按 Control-C 退出。需要 Apple Command Line Tools 与项目的
托管 LVGL 依赖。如果缺少 LVGL，先准备 ESP-IDF 5.5.3 并构建此项目一次。
优先复用已有 CMake 和 Ninja；缺少时自动安装固定版本到
`build/fortune-simulator/tooling` 下的独立环境。

## 体验实际按键

点击三个按钮，或使用键盘上、下、Enter。按住 0.5 秒为长按；也可以使用单独的长按按钮。

1. 首页确定从全部 2,200 条内容随机抽签。上／下打开独立主题页，主题用大字展示。
   在该页选择后按确定才生效并抽签，长按确定取消并回到全库首页。
2. 等信封展开，或按确定跳过。结果页上键再抽、下键换肤、确定留作签名。
3. 长按确定回首页。回首页或重启都会恢复全库随机，保留已读记录和已留签名。
4. 卡片页长按上调音量，上下调节，确定保存或长按确定取消；长按下开关音效。

页面显示实际抽取范围、未读数量、完整签文、诗词出处和最近记录。
**连续抽 20 张**复用应用按键流程并跳过拆信，沿用当前抽取范围，保留已留签名。
桌面诊断区选主题会打开主题选择页，开始抽取时才确认生效。

## 对比和复现

签库含 220 条诗词，占 10%。全库模式把所有内容一起打散，不安排主题配额，
同一轮不重复。短期可能没有诗词，也可能连续出现多张；不再保证每 20 张有两张诗词。
主动确认指定主题后，会持续抽该主题，直到回首页。只预览主题不会应用筛选。

新建空白模拟只重置本地模拟存档。在空白进度下指定同一个随机种子，可复现顺序。
例如当前实现中，种子 `42` 的前 20 次全库抽取含 4 张诗词。
重启模拟保留签名、外观、已读、音量和静音状态，抽取范围恢复全库。
刷新浏览器保留当前会话。导出记录包含全部抽取结果、种子、源码指纹与序列化模拟存档，方便定位问题。

## 复用了什么，模拟了什么

桌面程序直接编译 `main/main.c`，包括真实按键处理和存储编解码；链接相同的抽取模型、
签库、LVGL 界面、像素渲染器、中文字体和音乐生成器。设备画面没有另一套 JavaScript
随机逻辑，也不用浏览器字体重画签文。

桌面适配层替代 USB、按键、NVS、电池、音频设备及 RTOS 调度。
画面为 240 × 320 RGB565，复用 BSP 圆角遮罩，在浏览器放大展示；电池明确标为模拟值。
声音来自相同 PCM 乐谱，由 Mac 播放。编解码器响度、音频队列时序、实体按键阈值、
闲置功耗及设备性能仍需实机验证。模拟器不会打开 USB 或读写设备数据，
本地文件位于 `build/fortune-simulator/`。

## 验证

```bash
python3 tools/fortune_simulator/server.py --build-only
python3 tests/test_fortune_simulator.py
./tools/test_fortune_ui.sh
./tools/validate.sh
```

模拟器集成检查对比批量抽取与真实按键顺序，覆盖主题预览／确认／取消、重启后默认全库、
保存签名／音量／已读、记录导出，以及仅限本机的 HTTP 操作。
模型检查覆盖整轮不重复和全部诗词记录。主机测试不能证明实机验收通过。
